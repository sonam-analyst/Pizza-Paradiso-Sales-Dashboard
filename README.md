# 🍕 Pizza Paradiso Sales Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard created to analyze sales performance across multiple Pizza Paradiso branches.

The dashboard helps identify sales trends, compare branch performance, and understand customer preferences.

---

## 🎯 Objective

- Analyze branch-wise sales
- Compare pizza category performance
- Track KPIs
- Support business decision-making

---

## 🛠️ Tools Used

- Power BI
- Microsoft Excel
- Power Query

---

## 📊 Dashboard Features

- Branch slicers
- Pizza Type analysis
- Sales by Branch
- KPI Cards
- Interactive charts
- Filters

---

## 📈 KPIs

- Total Sales
- Total Orders
- Average Sales
- Best Selling Pizza
- Top Performing Branch

---

## 🔍 Key Insights

- Branch A generated the highest revenue.
- Classic pizzas contributed the highest sales.
- Weekend sales were higher than weekday sales.
- A few pizza categories generated most of the revenue.
